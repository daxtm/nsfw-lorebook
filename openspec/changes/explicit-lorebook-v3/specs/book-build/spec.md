# Spec Delta

## Purpose

One source file, one build command, one importable JSON, and checks that prove the book is safe to install on a 16K context.

## ADDED Requirements

### Requirement: Source of truth

`Kink & Explicit Scenes.card.txt` SHALL be the only hand-edited file. `Kink & Explicit Scenes.json` SHALL be generated by `python3 cardtool.py book "Kink & Explicit Scenes.card.txt" --out "Kink & Explicit Scenes.json"` and never hand-edited.

#### Scenario: Entry changes
- **WHEN** any entry is edited
- **THEN** the JSON is rebuilt from the source in the same step
- **How to check by hand:** note the JSON's timestamp, run the build, see it change.

### Requirement: Lint

`python3 cardtool.py lint` SHALL pass with only the two expected warnings (empty description and first_mes — this is a lorebook-only source).

#### Scenario: Lint runs
- **WHEN** lint runs on the finished book
- **THEN** no other warning appears
- **How to check by hand:** run the lint command; the warning count is exactly two.

### Requirement: Token gate

The tester SHALL fail if the whole book exceeds 16,000 tokens, if any entry exceeds 320, or if the worst of a set of reference scenes exceeds 2,600. Reference scenes use real matched entries rather than a fixed ten-entry slice, and randomized macro content is measured at its longest alternative.

#### Scenario: Book grows too large
- **WHEN** any gate trips
- **THEN** the run exits non-zero and prints the over-budget report
- **How to check by hand:** run `python3 tools/test_activation.py --budget`; it prints whole-book total, per-entry max and each reference scene's matched total. Counts are estimates, not guarantees.

### Requirement: Checks run standalone

`test_activation.py`, `test_selftest.py`, `test_build.py`, `check_vocab.py`, `check_keys.py`, `check_flags.py`, `check_coverage.py` and `check_phrases.py` SHALL each run on their own, print human-readable PASS/FAIL lines, and exit 0 on success.

#### Scenario: Check fails
- **WHEN** a check hits a fault
- **THEN** it names the file, the entry and what was expected
- **How to check by hand:** run `test_selftest.py`; each bad fixture must be reported by name.

### Requirement: Delivery

The finished book SHALL ship as whole files plus install steps in `README.md`: World Info panel → delete the old `Kink & Explicit Scenes` → Import `Kink & Explicit Scenes.json` → re-add to Active World(s) for all chats. No snippets to merge by hand.

#### Scenario: User installs from README
- **WHEN** the user follows the README end to end on a fresh import
- **THEN** they can install, verify and paste the phrase list without opening another file
- **How to check by hand:** follow the README exactly once, then delete the imported book and follow it again.

### Requirement: No new dependencies

All tooling SHALL use the Python 3.8+ standard library only.

#### Scenario: Tool added
- **WHEN** a tool is added or changed
- **THEN** it imports only standard-library modules
- **How to check by hand:** `grep -h '^import' tools/*.py | sort -u`; every module is stdlib.

### Requirement: Tool faults are readable

A missing source file SHALL fail with the path named, not a traceback. A book with zero entries SHALL fail the budget gate instead of passing at zero tokens. Em dashes and curly quotes SHALL survive the build, which writes UTF-8. Deleting an entry SHALL be safe: no tool may reference an entry by index. `test_build.py` SHALL compare a fresh build against the delivered JSON and fail when the export is stale.

#### Scenario: Source file moved
- **WHEN** the source file is absent
- **THEN** the build names the missing path and exits non-zero
- **How to check by hand:** rename the source, run the build, read the message, rename it back.
